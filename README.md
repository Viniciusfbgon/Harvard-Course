# 📘 CS50 – Introduction to Computer Science

Este repositório contém todos os projetos e exercícios que desenvolvi ao longo do curso, assim como o projeto final. **CS50: Introduction to Computer Science**, ministrado por **David J. Malan** na Universidade de Harvard.

---

## 🧠 Sobre o curso

CS50 é um curso introdutório ao mundo da ciência da computação que aborda desde os fundamentos de programação até conceitos mais avançados, como:

- Lógica e algoritmos
- Estruturas de dados
- Memória e compilação
- Programação Web
- Banco de dados
